# Weekly apply checklist

Copy this block into a new note (or reset the boxes) every Monday. Tracker: [`job-tracker.md`](./job-tracker.md) · Playbook: [`apply-playbook.md`](./apply-playbook.md)

**Week of:** _______________  
**Target mix:** ~70% Senior FE (Variant A) · ~30% FE-on-AI/agent (Variant B, only if agentic README is live)  
**Apps goal:** 8–12 tailored submissions

---

## Monday — target list

- [ ] Refresh LinkedIn saved searches + Easy Apply queue
- [ ] Check Wellfound for new Senior FE / AI-product FE roles
- [ ] Skim watchlist career pages (FinTech + AI product)
- [ ] Scan one remote-friendly board if LinkedIn is noisy
- [ ] Add **15–25** roles to tracker (`researching`)
- [ ] Score fit: stack (React/TS), seniority, remote, agentic overlap
- [ ] Promote fits to `ready-to-apply`; assign Variant **A** or **B**
- [ ] Cap this week’s apply queue at roles you can tailor (aim 8–12)

## Tuesday — applications

- [ ] Pick 3–4 `ready-to-apply` roles
- [ ] For each: tailored summary + 2–3 JD-matched bullets
- [ ] Attach correct resume variant (A or B)
- [ ] Submit; set tracker → `applied` + next action + notes
- [ ] Running total apps this week: ___ / 8–12

## Wednesday — applications

- [ ] Pick 3–4 more roles; same tailoring bar (no spray-and-pray)
- [ ] Prefer career page / referral over bare Easy Apply when possible
- [ ] Update tracker after each submit
- [ ] Running total apps this week: ___ / 8–12

## Thursday — applications + catch-up

- [ ] Finish remaining apps to hit **8–12** (or stop at 8 if quality would drop)
- [ ] Log any referrals or recruiter replies
- [ ] Flag roles that need Variant B / agentic demo before applying
- [ ] Running total apps this week: ___ / 8–12

## Friday — hygiene

- [ ] Follow up on stale apps (no ack / no screen)
- [ ] Move dead ends → `rejected` or `archived`; clear next actions
- [ ] Note JD/recruiter gaps → feed interview prep + agent learning
- [ ] Sketch Monday search themes (companies, titles, keywords)
- [ ] Confirm next week’s Variant A/B mix still ~70/30
