| Status | Meaning |
| --- | --- |
| researching | Role looks promising; still scoring fit (stack, seniority, remote, agentic overlap) |
| ready-to-apply | Fit scored; Variant A/B chosen; waiting on tailored summary + JD bullets |
| applied | Application submitted |
| follow-up | Sent or due for a nudge (recruiter / hiring manager / referral) |
| screen | Recruiter or hiring-manager screen scheduled or completed |

| offer | Offer received |
| rejected | Closed — no further action |
| archived | Withdrawn, duplicate, or no longer a fit |
